# Data File Formats

This folder contains sample text files used by the coursework application.

## `sample_login_data.txt`
Format:
`username,password,user_type,user_id`

## `sample_students.txt`
Format:
`student_id,core_module_1,core_module_2,core_module_3,core_module_4`

## `sample_modules.txt`
Format:
`module_or_activity_name,points,type`

## `sample_extra_activities.txt`
Format:
`student_id,activity_name,type,points`

## Notes
- These are **sample** records for demonstration and testing.
- Do not use this format for production credential storage.
